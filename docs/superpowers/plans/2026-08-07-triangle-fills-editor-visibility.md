# Triangle Fills And Editor Visibility Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make every triangle half-fill cover half of the visible triangle area and keep unused legend-editor appearance controls fully legible.

**Architecture:** Keep symbol geometry inside the shared SVG renderer and make clip generation depend on both base shape and fill pattern. Limit unused-state presentation changes to the editor CSS so the compact normal legend preserves its existing behavior.

**Tech Stack:** TypeScript, React, SVG, CSS, Node test runner.

## Global Constraints

- Triangle half fills represent 50% of visible shape area within normal SVG rendering tolerance.
- Unused enabled items remain fully editable and opaque in the legend editor.
- The compact normal legend retains its existing unused-item fading.
- No project schema or persisted symbol enum changes are introduced.

- [ ] **Step 1: Write failing renderer tests**

- [ ] **Step 2: Run the focused test and verify failure**

- [ ] **Step 3: Implement shape-aware clips**

This retains the existing top, bottom, left, right, or upper-left diagonal direction while producing equal-area clip polygons, the existing neutral base, and the shared outline.
